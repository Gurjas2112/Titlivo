# References: research, publications and news

Background reading for the problem Titlivo works on: land records spread across disconnected state systems, titles that are presumptive rather than guaranteed, repeated due diligence, and fraud that happens after a check is done. Each entry has a one-line takeaway. Figures differ between sources and dates, so the takeaways say where and when a number comes from. Checked 1 November 2026.
